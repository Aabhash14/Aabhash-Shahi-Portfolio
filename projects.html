Selected work

A selection of projects where I solved real quality and engineering problems. Each one opens a full case study.

Agentic AI workflow

One-flow QA: cases, scripts, run, ticket

Takes a feature and returns a filed bug ticket — generates the test cases, generates the scripts, runs them, drafts the report and raises the Azure DevOps ticket, with no manual handoff between steps.

Impact Manual copy-paste removed from the QA cycle
AI documentation agent

Technical and functional docs, generated

An agent that reads the codebase and produces both registers of documentation — technical detail for developers, functional description for the client — instead of each being written by hand per project.

Impact Docs refreshed on change, not rewritten
QA platform

Client QA dashboard

One place holding all test data, run history and documentation per product, so the client can judge release risk without someone assembling the answer from pipeline logs.

Impact Release risk readable from one screen
Automation framework

Playwright suite in continuous regression

Introduced Playwright in 2023 and wired it into Azure Pipelines with JUnit and HTML reporting, so regression runs after every commit rather than whenever there was time for a manual pass.

Impact Regression on every commit, not on request
API automation

API test automation in Postman

Moved API coverage from a folder of saved requests someone had to click through to an automated suite asserting on contract, payload and error paths, with SQL verification behind it.

Impact Contract defects caught before the UI
Quality process

QA standards and test strategy from zero

There was no QA process to inherit. I wrote the standards, entry and exit criteria and defect workflow the team still works to, and worked the untested backlog down application by application.

Impact Every backlog app brought under coverage
