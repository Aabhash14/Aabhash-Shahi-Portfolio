About me

I started at Proshore as a QA intern in 2023 and grew into the company's entire quality function — now the only QA engineer for nine developers across four De Heus products. There was no QA process to inherit at any point: no test plans, no case repository, no defect workflow, and a backlog of applications that had never been systematically tested.

So I built it. QA standards and a test strategy the team still works to, a test case library in Azure DevOps, and a Playwright suite running continuously through Azure Pipelines rather than on request. Then I went below the interface: API testing, database testing, and SQL verification of the pricing and contract data the client's business actually depends on.

The bottleneck was never execution — it was authoring. So I built agentic AI workflows that generate test cases and scripts, run them, produce the bug report and raise the ticket in one flow, plus an agent that writes technical and functional documentation from the codebase. I care about the part of quality that survives after I leave a project: documentation someone else can follow, suites that don't rot, and reporting a stakeholder can read without opening a test log.
