About me

Started as a QA Intern in 2023 and progressed to owning the company’s end-to-end quality function, becoming the sole QA Engineer supporting nine developers across multiple De Heus products. Established QA processes from the ground up where no formal testing infrastructure existed, including test plans, test case repositories, defect workflows, and systematic testing practices for previously untested applications.

Built the company’s QA practice from the ground up, establishing QA standards implemented by the team, along with a centralized test case library in Azure DevOps. Designed and integrated a Playwright automation suite into Azure Pipelines for continuous CI/CD execution, shifting automated regression from on-demand testing to an ongoing quality gate. Expanded testing beyond the UI to API and database layers, using SQL to validate critical parts underlying client business operations.

Engineered agentic AI workflows to streamline the end-to-end QA lifecycle, automating test-case and script generation, execution, defect analysis and reporting, and ticket creation within a unified workflow. Developed an AI-powered documentation agent that generates technical and functional documentation from the codebase. Designed these systems to improve long-term quality ownership for maintainable automation, reusable documentation, and clear stakeholder reporting that remain effective beyond individual project contributors.
